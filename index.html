Customization example

Customize component behavior by setting variables. Try opening DevTools and toggling these in the :root:

--fc-heading-letter-spacing: -0.04em;
--fc-anchor-text-decoration: underline;
--fc-cluster-space: 3rem;
--fc-focus-ring: 3px dashed var(--fc-color-link);

All customization variables are documented in src/tokens.css. In your project, set them in a theme file that imports fluff-css first.
